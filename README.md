# 电机测控与调试上位机 (Motor Test Station)

现代工业级 Web 串口电机调试上位机，基于 **HTML5 + Web Serial API + Canvas 示波器** 开发。针对 STM32 单片机通信链路设计，纯前端自包含架构，无需安装额外驱动或笨重环境，使用现代浏览器即可直接连机调试。

---

## 一、核心特性

1. **工业级硬核仪表台 UI 设计**
   - 采用深空黑蓝低反光面板（Cyber-Industrial Instrumentation Aesthetic），高对比度刻度与发光指示器。
   - 大号发光液晶 LCD 风格数字大屏实时显示实测输出电压（通道 A）与实测扭矩反馈（通道 B），自动记录并显示极值。
   - 交互按键、旋钮式大滑块、常用档位预设胶囊按钮与一键大红色急停按钮（0.00 V）。

2. **高性能 60 FPS 实时双通道示波器**
   - 纯原生 Canvas 双通道自适应渲染（电压青蓝光晕曲线 + 扭矩机械琥珀金曲线）。
   - 包含背景时间/分度栅格网格、双侧独立 Y 轴刻度、半透明面积渐变阴影。
   - **交互探针（Crosshair Tooltip）**：鼠标滑动悬停时自动显示虚线准星与该时刻采样点的精确物理量数值。
   - 支持实时动态滚动、一键暂停分析、清空波形与**一键导出 CSV 历史采样数据**（包含相对时间戳、电压、扭矩）。

3. **专为单片机定制的高可靠性通信引擎**
   - 严格匹配 14 字节小端对齐协议，支持 **CRC-16/CCITT-FALSE** 完整性校验。
   - 内置流式解包器（`StreamUnpacker`），能够自动纠错、过滤前端噪点、处理串口字节分片与粘包。
   - 实时统计并展示通信指标：RX 有效帧数、TX 发送次数、实时通信帧率 (FPS / Hz)、CRC 校验错误数。

4. **内置高真实感电机仿真器 (Mock Simulator)**
   - 脱机或无硬件环境时，一键启动“仿真模式”。
   - 仿真单片机以 20 Hz (50 ms) 持续上报真实带有动态阻尼响应与热噪声的电压与扭矩反馈帧。
   - 仿真器能实时响应上位机下发的目标电压调节并产生平滑的一阶惯性过渡，便于无硬件时随时演示与调试。

## 二、通信协议速查

双向通信均为固定 **14 字节二进制小端帧**，无字符串与换行：

| 字节偏移 | 长度 | 下行：上位机设置输出目标电压 | 上行：单片机上报测量反馈 |
| :---: | :---: | :--- | :--- |
| **0** | 1 | 帧头 `0xA5` | 帧头 `0xA5` |
| **1** | 1 | 协议版本 `0x01` | 协议版本 `0x01` |
| **2** | 1 | 消息类型 `0x01` (SetVoltage) | 消息类型 `0x81` (Feedback) |
| **3** | 1 | 发送序号 (0 ~ 255) | 单片机发送序号 (0 ~ 255) |
| **4 ~ 7** | 4 | 目标输出电压 `V_target` (Float32, 小端) | 实测输出电压 `V_feedback` (Float32, 小端) |
| **8 ~ 11** | 4 | 保留位 (全 0) | 实测机械扭矩 `Torque_feedback` (Float32, 小端) |
| **12 ~ 13** | 2 | CRC-16 (低字节在前，小端) | CRC-16 (低字节在前，小端) |

- **CRC 算法**：CRC-16/CCITT-FALSE（多项式 `0x1021`，初值 `0xFFFF`，无反射，异或值 `0x0000`）。
- **校验范围**：前 12 字节（偏移 0 ~ 11）。

## 三、快速使用指南

### 1. 运行方式

本上位机采用纯静态标准 Web 技术构建：

- **直接双击**：在文件资源管理器中直接双击打开 `index.html`（或拖拽到 Chrome / Edge 浏览器窗口中）。
- **静态服务器**（可选）：在当前目录下运行 `python -m http.server 8080`，然后在浏览器访问 `http://localhost:8080`。

> **浏览器要求**：连接真实串口硬件需要浏览器支持 **Web Serial API**，推荐使用 **Google Chrome**、**Microsoft Edge** 或 **Opera**（版本 89+）。
> 若使用 Firefox 或 Safari，仍可使用内置的【仿真模式】体验完整的控制与示波器绘制功能。

### 2. 操作流程

1. **连接硬件**：将单片机的 USB-TTL 串口（如 USART3 对应的 TX/RX）接入电脑 USB，确认波特率为 `115200`，点击顶部【连接串口】并在浏览器弹出列表中选择对应的 COM 口。
2. **设定电压**：
   - 可直接拖动大号电压滑块或通过右侧 `+/-` 按钮进行 ±0.2 V 微调。
   - 点击预设胶囊档位（如 `3.3V`、`5.0V`、`12.0V` 等）快速切换。
   - 点击【立即下发目标】发送给单片机（若勾选实时同步，拖动时会自动以 20 Hz 节流发送）。
   - 如遇异常，可随时点击红色【一键急停 (0V)】。
3. **观测与记录**：
   - 右侧上方大屏实时刷新电压与扭矩，并记录当前会话的极值。
   - 示波器实时滚动双通道波形，可随时点击【暂停采样】分析波形细节，或点击【导出 CSV】下载数据文件。
   - 底部报文监视器可勾选“详细打印十六进制数据”查看底层 14 字节原始报文流。

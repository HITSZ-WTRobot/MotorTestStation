# 电机测控与调试上位机 (Motor Test Station - Cleanroom Edition)

现代高精度 Web 串口电机调试上位机，基于 **HTML5 + Web Serial API + Canvas 示波器** 开发。针对 STM32 单片机通信链路设计，纯前端自包含架构，无需安装额外驱动或笨重环境，使用现代浏览器即可直接连机调试。

---

## 一、核心特性

1. **Cleanroom 纯白 + 淡蓝极客实验室 UI 设计**
   - 采用纯白面板（`#ffffff`）搭配浅冰蓝蓝图底衬（`#f1f6fb`）与电离湛蓝高光（`#0284c7`），高对比度刻度与状态指示器。
   - 大号高对比度数显大屏实时显示实测输出电压（通道 A）与实测绝对值扭矩（通道 B），集成实时动态发光量程条。
   - 多模式选项卡切换：**【⚡ 手动电压调试】**、**【🎯 扭矩闭环控制 (TIM3 100Hz)】**、**【⚙️ 下位机参数调优】**、**【📡 通信链路与协议】**。

2. **支持外环扭矩闭环、前馈与动态电压上限 (Vmax / Vff)**
   - 匹配下位机最新外环 PID 扭矩控制架构（绝对值卡尔曼滤波闭环）。
   - 依据最新控制策略，集成**前馈基准与动态电压上限提示 (Vmax / Vff)**：按前馈基准 $V_{\text{ff}} = T_{\text{target}} / 0.5$ 并增加 **$+0.5\text{ V}$ 裕量** 计算动态输出上限 $V_{\text{max}} = \min(V_{\text{ff}} + 0.5\text{ V}, 18.0\text{ V})$，避免单纯前馈导致电压不足无法达到目标。
   - 降低安全上限 `TorqueLimit` 时自动调用 `GetState` 刷新被钳位目标及动态限幅值。
   - 包含扭矩闭环开启/关闭、软件紧急停机（输出归零并清空 PID 状态）。
3. **下位机 6 参数在线调优与 Flash 安全保存流程**
   - 支持在线读取与修改下位机 6 项 RAM 参数：`Kp`、`Ki`、`Kd`、`Q (过程噪声)`、`R (测量噪声)`、`TorqueLimit (上限幅值)`。
   - 严格遵循交接文档规定的**停机安全保存流程**：
     1. 停止当前输出并关闭扭矩闭环；
     2. 逐项写入已修改参数到下位机 RAM；
     3. 触发 `SaveParameters (0x12)` Flash 写入；
     4. 校验 `0x82` 响应与存储状态码（StorageCode）。

4. **高性能 60 FPS 实时双通道示波器**
   - 原生 Canvas 双通道实验室分度渲染（电压湛蓝曲线 + 扭矩机械琥珀金曲线）。
   - 包含 Tektronix 规范的双侧独立标定刻度、半透明面积渐变阴影。
   - **交互探针（Crosshair Tooltip）**：鼠标滑动悬停时自动显示虚线准星与该时刻采样点的精确物理量数值。
   - 支持实时动态滚动、一键暂停分析、清空波形与**一键导出 CSV 历史采样数据**。

5. **单请求在途（Single Flight）高可靠性通信引擎**
   - 内置串行请求队列，严格保障下位机 8 项 FIFO 不被洪泛溢出。
   - 严格匹配 14 字节小端对齐协议，支持 **CRC-16/CCITT-FALSE** 完整性校验。
   - 流式解包器（`StreamUnpacker`）同时支持 `0x81` 测量反馈与 `0x82` 命令应答。

6. **内置全功能虚拟下位机仿真器 (Mock Simulator)**
   - 脱机或无硬件环境时，一键启动“仿真模式”。
   - 完整模拟下位机状态机、RAM/Flash 参数读写、100Hz 扭矩外环 PID 动态响应与 14 字节双向协议交互。

## 二、通信协议速查 (v0x01)

双向通信均为固定 **14 字节二进制小端帧**，无字符串与换行，CRC16/CCITT-FALSE（前 12 字节校验）：

| 字节偏移 | 长度 | 下行命令帧 (0x01 ~ 0x13) | 上行反馈帧 (0x81) | 上行应答帧 (0x82) |
| :---: | :---: | :--- | :--- | :--- |
| **0** | 1 | 帧头 `0xA5` | 帧头 `0xA5` | 帧头 `0xA5` |
| **1** | 1 | 版本 `0x01` | 版本 `0x01` | 版本 `0x01` |
| **2** | 1 | 命令类型 (`0x01` ~ `0x13`) | 消息类型 `0x81` | 消息类型 `0x82` |
| **3** | 1 | 请求序号 (0 ~ 255) | 反馈序号 (0 ~ 255) | 回显请求序号 (0 ~ 255) |
| **4 ~ 7** | 4 | word0 (浮点/整型参数) | 实测电压 `V_feedback` (Float32) | 状态字 (Result \| Enabled<<8 \| Valid<<9 \| Cmd<<16) |
| **8 ~ 11** | 4 | word1 (浮点/整型参数) | 实测扭矩 `Torque_feedback` (Float32) | 应答数值 `Value` (Float32) |
| **12 ~ 13** | 2 | CRC-16 (低字节在前，小端) | CRC-16 (低字节在前，小端) | CRC-16 (低字节在前，小端) |

## 三、快速使用指南

### 1. 运行方式
直接用电脑上的 **Chrome** 或 **Edge** 打开 `串口.html`：
- **路径**：`D:\omp\stm32dbg\motor test debug\串口.html`
- 若要在其他电脑上运行，只需复制单文件 `串口.html` 即可。

### 2. 操作流程
1. **连接硬件/仿真**：
   - 插入 USB-TTL 串口（USART3 115200 8N1，PC10-TX / PC11-RX），点击【连接串口】。
   - 无硬件时点击【仿真模式 (Mock)】体验全功能控制与闭环波形。
2. **模式调试**：
   - **手动电压**：拖动滑块或快捷按键设定目标电压，点击【下发电压目标】。
   - **扭矩闭环**：切换到【🎯 扭矩闭环】标签，设定目标扭矩幅值，点击【下发扭矩目标】，点击【▶ 开启扭矩闭环】。
   - **参数保存**：切换到【⚙️ 下位机参数】标签，修改参数后点击【应用到设备 (RAM)】；需要掉电保存时点击【💾 停机安全保存到 Flash】。
